## Présentation de l'application 
>Notre application du puissance 4 est basée sur le jeu du même nom. Vous pouvez la lancer avec plusieurs clients qui pourront s'affronter. Elle a été développé en Java.
## Utilisation de l'application
### Maven
>Nous avons mis en place Maven pour pouvoir organiser notre projet.
### Lancement de l'application
>Pour pouvoir lancer le puissance 4, il faut tout d'abord compiler les fichiers source et ensuite lancer l'application avec la commande: "**mvn clean compile exec:java**"
